# Third-party components in the Windows x64 Lite setup

- CPython 3.13.17 comes from the official Windows embeddable archive. Its notice is in `runtime/python/LICENSE.txt`. The 19 pinned Python wheels retain their license files, and `python-wheel-inputs.json` records their URLs and hashes. [Python release](https://www.python.org/downloads/release/python-31317/)
- FFmpeg and FFprobe use the shared x86-64 build dated 2026-11-16. The installed avutil library reports LGPL version 3 or later. Its embedded configure flags are in `runtime/bin/FFMPEG-BUILD-CONFIG.txt`, and the supplied license is in `runtime/bin/LICENSE-FFmpeg.txt`. [Binary release](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases/tag/autobuild-2026-11-16-15-29) · [FFmpeg source revision](https://github.com/FFmpeg/FFmpeg/commit/d838f9f9ae)
- PocketSphinx 5.1.1 provides English phoneme alignment. The package retains its executable license and the notices in the acoustic model directory. [PocketSphinx source release](https://github.com/cmusphinx/pocketsphinx/releases/tag/v5.1.1)
- eSpeak NG 1.52.0 provides pronunciation support. Its x86-64 library uses `N_PATH_HOME=4096`. The packaged data comes from its Windows release. The license, bundled dependency notices, and library and data hashes are in `runtime/espeak/`. [eSpeak NG source release](https://github.com/espeak-ng/espeak-ng/releases/tag/1.52.0)
- NSIS 3.09-4 builds the setup program. The executable contains the NSIS stub, the LZMA extractor, and nsExec. The build package’s copyright and license text is in `runtime/nsis/COPYRIGHT`. [NSIS licenses](https://nsis.sourceforge.io/License)
- The AWS SDK for Python supports Amazon Polly. The same manifest pins its wheels, which retain their license notices. [Boto3 source](https://github.com/boto/boto3)
